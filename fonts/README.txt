Faruma font for Dhivehi
=======================
Put your Faruma font file in this folder with ONE of these exact names:

  faruma.ttf      (normal font file)
  faruma.woff2    (smaller web version – optional, loads faster)

Then push to GitHub. The app will use Faruma for all Dhivehi (Thaana) text:
labels, names typed in Dhivehi, receipts on screen and the tracking page.

If no file is here, phones that already have Faruma installed still use it,
and other phones use the free "Noto Sans Thaana" font instead.

Only add a Faruma file you are allowed to use and share on a website.
